# 🌿 Tenang

**Tenang** adalah web app yang membantu kamu mengurangi doom scrolling dan lebih sadar dengan waktu digital.

**Live:** https://USERNAME.github.io/tenang-deploy/

---

## Fitur (Phase 1)

- Onboarding 4 langkah dengan data demo
- Dashboard harian: batas waktu, streak, ringkasan
- Session Timer dengan countdown circular & notifikasi
- Pencatatan manual (duration + mood before/after)
- Statistik: bar chart + hourly heatmap
- Pengaturan: nama, tema, batas, jam rawan
- 100% data lokal (localStorage), tanpa backend

## Cara Buka

Buka `index.html` langsung di browser — **tidak perlu build, tidak perlu server**.

Atau akses via GitHub Pages setelah deploy.

---

## Stack

- Pure HTML + CSS + Vanilla JavaScript
- Zero dependencies, zero build step
- Responsive, dark mode, accessible
